# Spec: M1 first working loop

**id:** M1   **intent:** .buildloop/intent/M1.md
**policies applied:** global CLAUDE.md (Swift/SwiftUI, no deps, no em-dashes)
**status:** accepted (originator supplied the design and acceptance criteria)

## Summary
SwiftUI app `PhotoCleanup` (repo `pictr`) generated by XcodeGen. PhotoKit is wrapped
by `PhotoLibraryClient`; assets are converted to Sendable `AssetDescriptor` values on a
background queue; pure `Bucketer` + `SizeProvider` code does the analysis; a
`@MainActor @Observable LibraryModel` drives the UI.

## Requirements
R1. Auth flow for notDetermined, authorized, limited, denied, restricted.
R2. Fetch user-library assets created in the last 30 days; PHFetchResult kept lazy.
R3. Bytes per asset via SizeProvider: exact (sum of every PHAssetResource "fileSize", KVC,
    defensive) else estimated (pixels x UTType, duration x nominal bitrate). Each result
    records exact vs estimated. Off main actor, with progress.
R4. Buckets: Screenshots, Burst extras (non-pick frames; keep first frame if no pick),
    Large videos (>= 100 MB, one constant). Favorites and hidden never bucketed.
R5. Bucket list: count, total bytes (ByteCountFormatter), "estimated" marker; header
    shows total reclaimable (unique assets).
R6. Bucket detail: thumbnail grid, all selected, tap toggles, "Delete N (X GB)".
R7. One performChanges per commit; cancel is not an error; observer reconciles.
R8. Space summary: queued, moved to Recently Deleted this session, not on this iPhone.
    The word "freed" never appears in the UI.
R9. Thumbnails with isNetworkAccessAllowed = false; iCloud-only shows placeholder + flag.

## Acceptance criteria
AC1. Builds with zero warnings in Swift 6 mode | `xcodebuild build` with SWIFT_TREAT_WARNINGS_AS_ERRORS=YES, warning count 0
AC2. Bucketing rules unit-tested on fake descriptors | `xcodebuild test` BucketerTests pass
AC3. SizeProvider fallback estimation unit-tested | `xcodebuild test` SizeProviderTests pass
AC4. Bucket totals equal the sum of members | BucketerTests asserts totals
AC5. No network code | `grep -rE "URLSession|NWConnection|import Network|URLRequest" PhotoCleanup` empty
AC6. No "freed" in UI strings | `grep -rni freed PhotoCleanup` empty
AC7. On-device: buckets populate, delete shows Apple's sheet, cancel leaves state, list updates without relaunch | manual, on a physical iPhone (originator)

## Ordering surface
concurrency: PHPhotoLibraryChangeObserver callbacks arrive on an arbitrary queue while
the scanner actor may be mid-scan; deltas must apply after the snapshot they refer to.

## Rejected alternatives
- Mapping PHAsset into the UI directly: not Sendable, untestable.
- Async sizing per asset with TaskGroup: resource reads are cheap sync calls; a single
  serial pass with throttled progress is simpler and deterministic.
